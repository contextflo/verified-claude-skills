# Ecommerce warehouse (thelook_ecommerce): schema

`bigquery-public-data.thelook_ecommerce` is a synthetic clothing store generated by Google. It is shaped like a typical ecommerce warehouse; it is not Shopify's schema. All tables are flat (no nested fields). Timestamps are UTC `TIMESTAMP`.

## Tables and grain

| table | grain | rows (2026-11-05) |
|---|---|---|
| `orders` | one order | 124,452 |
| `order_items` | one unit sold (no quantity column) | 180,746 |
| `products` | one product | 29,120 |
| `inventory_items` | one physical unit in stock, sold or not | 487,914 |
| `users` | one customer account | 100,000 |
| `events` | one web event (page or action) | about 2.4M |
| `distribution_centers` | one warehouse | 10 |

## Joins

```
users.id                  = orders.user_id = order_items.user_id = events.user_id
orders.order_id           = order_items.order_id
order_items.product_id    = products.id
order_items.inventory_item_id = inventory_items.id
inventory_items.product_distribution_center_id = distribution_centers.id
products.distribution_center_id                = distribution_centers.id
```

## Key columns

**orders**: `order_id`, `user_id`, `status` (`Processing`, `Shipped`, `Complete`, `Cancelled`, `Returned`), `created_at`, `shipped_at`, `delivered_at`, `returned_at`, `num_of_item`, `gender`.

**order_items**: `id`, `order_id`, `user_id`, `product_id`, `inventory_item_id`, `status` (same values as orders, and the same for every item in an order in this data), `created_at` (differs from `orders.created_at`), `shipped_at`, `delivered_at`, `returned_at`, `sale_price`.

**products**: `id`, `name`, `brand`, `category`, `department` (`Men`, `Women`), `sku`, `retail_price`, `cost`, `distribution_center_id`.

**inventory_items**: `id`, `product_id`, `cost`, `created_at`, `sold_at` (always NULL for sold units here), and copies of the product fields (`product_category`, `product_name`, `product_brand`, `product_retail_price`, `product_department`, `product_sku`, `product_distribution_center_id`).

**users**: `id`, `first_name`, `last_name`, `email`, `age`, `gender`, `street_address`, `city`, `state`, `postal_code`, `country`, `latitude`, `longitude`, `user_geom`, `traffic_source` (at signup), `created_at`.

**events**: `id`, `user_id` (NULL for anonymous visitors), `session_id`, `sequence_number`, `created_at`, `event_type` (`home`, `department`, `product`, `cart`, `purchase`, `cancel`), `uri`, `traffic_source`, `browser`, `ip_address`, `city`, `state`, `postal_code`.

**distribution_centers**: `id`, `name`, `latitude`, `longitude`, `distribution_center_geom`.

## Not in this dataset

Discounts, coupons, tax, shipping charges, payment fees, refunds as separate transactions, partial returns, multi-currency, subscriptions. Real stores have most of these, and they change every margin and LTV number.
